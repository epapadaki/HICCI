Getting started

  1. Add a dataset. On Datasets, choose an .h5ad file, check the columns the platform suggests (cell types, and optionally samples and groups), and prepare it.
  2. Run a tool. Choose one tool (CellPhoneDB, NATMI, CellChat, SingleCellSignalR or ICELLNET); Which tools suit this dataset? recommends one for your data. Press Run; the progress is shown on the card. You can later run another tool and switch between their results; running several tools together to compare them is an advanced option.
  3. Explore. Interactions lists every interaction with the tools that report it, and Tools how the tools overlap.
  4. Assess. In the interactions table, every interaction is kept by default; uncheck the Assessment box on any row to remove it. Enter your name in the Reviewer field first.

Describe your experiment with Experiment details in the top bar (tissue, condition). The Case study relevance tab then compares each publication with it.

Reading an interaction

The documentation panel separates three kinds of information, marked by a coloured bar:

  • Computed from your data: the tools’ predictions and the expression of the ligand and receptor in your cells.
  • About this pair: what publications report about this ligand–receptor pair.
  • About the receptor in general: curated knowledge of the molecules and of receptor signalling, whatever ligand binds.

Tabs: Prior knowledge (mechanism picture, molecule functions, pathways), Literature support, Case study relevance (how close each study is to your experiment), Case study (expression in your populations) and Signalling response.

A prediction is a candidate from RNA expression. It does not show that the proteins bind, that the receptor is activated or that a pathway is active in your sample.

Terms

Data sources

Local copies are used so that analyses are reproducible and work offline. Dates are when each copy was made.

SourceUsed forLocal copy

Each analysis also writes an analysis record with the exact versions and checksums (Datasets, Check report).

Citing

If you use results from the platform, please cite the platform (reference to be added on publication) and the original publications of the tools and databases you relied on: CellPhoneDB, NATMI, CellChat, SingleCellSignalR, ICELLNET, UniProt, Reactome and SIGNOR. The analysis record of each dataset lists the versions used and offers a draft Methods paragraph.
